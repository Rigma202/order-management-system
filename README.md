# Order Management System

A simple Laravel-based Order Management System built using Laravel.

This project allows admins to manage customers, products, and orders from a dashboard interface.

---

## Features

### Authentication
- Laravel Breeze Authentication
- Protected dashboard access

### Customer Management
- Add Customer
- Edit Customer
- Delete Customer
- View Customer List

### Product Management
- Add Product
- Edit Product
- Delete Product
- Product Search


### Order Management
- Create Orders
- Select Customer
- Add Multiple Products
- Automatic Total Calculation
- Stock Quantity Update


### Dashboard
- Customer Listing
- Product Listing
- Orders



## Implemented Functionalities

1 Authentication  
2 Customer CRUD  
3 Product CRUD  
4 Order Management  
5 API Development  
6 Validations & Error Handling  




## Technologies Used

- Laravel
- PHP
- MySQL
- Blade Templates
